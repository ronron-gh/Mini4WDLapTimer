# Mini4WDLapTimer

M5Stack Core ESP32とVL53L0X ToFセンサーを使うミニ四駆ラップタイマーです。現在は実装第4段階（隠し50回測定）まで進んでいます。

## 現在の動作

- 起動時にセンサーを一度だけ初期化し、Continuousモードを維持します。
- Aボタンで未取得結果1件を読み捨てた後、車体がいないコースまでの距離10件の平均を取得します。
- 基準距離から20mm以上短くなると通過を検出し、最初の通過で開始、以後10周まで記録します。
- 復帰の距離差は10mm以下。通過後1秒間は次の検出を受け付けません。
- Aボタンで計測をリセットして基準距離を再取得します。センサーは停止・再初期化しません。
- LCDの1画面に10周分のラップ・累積時間、現在経過時間、状態・校正進捗・エラーを表示します。
- 左下のA案内は待機中が「スタート」、その他の通常状態が「リセット」です。
- 基準距離10サンプルの平均を115200bpsのSerialへ確定後に1回出力します（例：BASELINE SESSION=2 SAMPLES=10 DISTANCE_MM=300.5）。LCDは最大20Hz、Serialは最大2Hzです。
- ラップ表のSerial出力はsrc/TimerTasks.cppの「Debug lap output」2か所をコメントアウトしています。デバッグ時は宣言ブロックと呼び出しブロックのコメントを外すと従来の出力を復元できます。outputSerial()本体はsrc/TimerDisplay.cppに残しています。
- 3タスクで測定・ボタン入力・表示を分離しています。

## ビルドと使用

```text
pio run
pio run -t upload
pio device monitor
```

基準距離取得時にはセンサー下から車体を離してください。設定はinclude/LapTimer.hとinclude/SensorReader.hを参照してください。測定時間設定値20ms、I²C 400kHz、通信タイムアウト20ms、取得タイムアウト1000msです。時刻は起動後経過時間をµsで保存します。時間表示は秒、小数2桁です。

取得エラー時は計測を終了し、確定済み結果を保持します。Aで復帰を試みますが、起動時のセンサー初期化失敗は本体リセットが必要です。

## 後続段階と保持機能

10周分のLCD表示は実装済みです。Serialのラップ表はデバッグ用に保持し、通常は基準距離の平均結果だけを出力します。待機状態でCボタンを3秒間長押しすると、隠し50回測定へ移ります。測定中は描画・出力を止め、完了後に全50行のCSVと集計をSerialへ出します。終了画面に取得数・成功数・間隔の最小／平均／最大を表示します。

隠し機能内ではAボタンで再測定できます。準備・測定・出力中のAは、出力終了後の再測定を1回予約します。Cは無視します。通常のラップタイマーに戻るには本体をリセットしてください。センサーは再測定でも停止・再初期化しません。

既存の50回測定はBenchmarkクラスに保持しています。capture()がRAMに記録し、printResults()が従来のCSVと集計を出力します。通常起動では自動実行せず、C長押しから測定タスクで逐次捕捉し、表示タスクが出力します。センサーの停止・再起動処理はありません。
