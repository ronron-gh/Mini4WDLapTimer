# Mini4WDLapTimer

M5Stack Core ESP32とVL53L0X ToFセンサーを使うミニ四駆ラップタイマーです。現在は実装第2段階（RTOSタスクとセンサー連携）まで進んでいます。

## 現在の動作

- 起動時にセンサーを一度だけ初期化し、Continuousモードを維持します。
- Aボタンで未取得結果1件を読み捨てた後、車体がいないコースまでの距離10件の平均を取得します。
- 基準距離から20mm以上短くなると通過を検出し、最初の通過で開始、以後10周まで記録します。
- 復帰の距離差は10mm以下。通過後1秒間は次の検出を受け付けません。
- Aボタンで計測をリセットして基準距離を再取得します。センサーは停止・再初期化しません。
- LCDは第2段階の簡易状態表示です。結果は115200bpsのSerial診断で確認できます。
- 3タスクで測定・ボタン入力・表示を分離しています。

## ビルドと使用

```text
pio run
pio run -t upload
pio device monitor
```

基準距離取得時にはセンサー下から車体を離してください。設定はinclude/LapTimer.hとinclude/SensorReader.hを参照してください。測定時間設定値20ms、I²C 400kHz、通信タイムアウト20ms、取得タイムアウト1000msです。時刻は起動後経過時間をµsで保存します。時間表示は秒、小数2桁です。

取得エラー時は計測を終了し、確定済み結果を保持します。Aで復帰を試みますが、起動時のセンサー初期化失敗は本体リセットが必要です。

## 後続段階と保持機能

完成した10周分のLCDとSerialの画面相当表示は第3段階で追加します。Cボタン長押し3秒の隠し機能は第4段階で接続します。

既存の50回測定はBenchmarkクラスに保持しています。capture()がRAMに記録し、printResults()が従来のCSVと集計を出力します。第2段階では通常起動やボタン操作から呼び出しません。センサーの停止・再起動処理はありません。
